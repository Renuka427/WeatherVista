WeatherVista 🌤️
Overview
Welcome to WeatherVista, your stylish and interactive weather app that brings real-time forecasts to life! With WeatherVista, you can easily access detailed weather information such as temperature, humidity, wind speed, and more, all displayed with dynamic, weather-responsive backgrounds. 🌧️🌞

Get ready to experience the forecast like never before—WeatherVista turns checking the weather into an enjoyable, visually immersive experience. Whether it’s a sunny day, rainy afternoon, or snowy evening, the app updates to reflect the conditions around you with stunning animations and smooth transitions.

Features
Real-time Weather Data 🌎: Get current weather details including temperature, humidity, wind speed, and more.
Dynamic Backgrounds 🌈: Backgrounds that change based on the weather (sunny, rainy, snowy, etc.), bringing the forecast to life.
Smooth Animations ✨: Enjoy subtle animations and hover effects on icons and weather elements.
Responsive Design 📱: Optimized for both mobile and desktop devices, so you can check the weather wherever you are.
Weather-Dependent Visuals 🎨: Experience unique visual designs that adapt to weather conditions (like rain or snow), making each forecast visually distinct and engaging.
Interactive UI 🖱️: The app features interactive weather icons that respond to user interactions, creating a playful experience while checking the weather.
Tech Stack
HTML5: Basic structure and layout of the application.
CSS3: Styling with dynamic backgrounds, animations, and responsive design.
JavaScript: Fetching real-time weather data and updating the UI dynamically.
Weather API: Powered by WeatherAPI for accurate, real-time weather updates.
How to Use
Enter the name of a city into the search box.
Click Search to retrieve the weather data for that city.
View the current temperature, weather description, humidity, wind speed, and more.
Enjoy the dynamic background that changes based on the current weather!
